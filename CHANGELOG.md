## [2026-06-08] — Видимость для админа: активность, инвайты, live-статистика

### Added
- **Активность пользователей**: при входе в панель пишется `last_login_at`, при
  обращении к боту — `last_bot_at` (в т.ч. после регистрации по коду).
- В списке пользователей — **код регистрации**, последний вход в панель, последняя
  активность в боте, дата последнего сброса трафика (если стратегия не «никогда»).
- В модалке конфигов (admin/support) — **live-статистика с серверов**: онлайн/офлайн,
  handshake, трафик ↓/↑, дата создания (один SSH-сеанс на сервер).
- В списке инвайт-кодов — **кто создал** и **кто использовал** (telegram_id + дата).

### Changed
- API `/api/users`, `/api/users/{id}/connections`, `/api/invite-codes` расширены
  соответствующими полями.

## [2026-06-08] — Автобэкап в S3 (data.json + SECRET_KEY)

### Added
- **Автобэкап в закрытый S3-бакет** (AWS S3 и совместимые хранилища: MinIO и т.п.).
  В настройках панели — блок «Автобэкап в S3»: endpoint, bucket, prefix, ключи
  доступа, интервал (часов), ротация (хранить последних N копий).
- Каждый бэкап — **три объекта** в папке `{prefix}/YYYY-MM-DDTHH-MM-SSZ/`:
  - `data.json` — состояние панели (как на PVC, с `enc::v1::`);
  - `secret.key` — `SECRET_KEY` из env (для восстановления пары);
  - `manifest.json` — sha256, счётчики серверов/пользователей, версия панели.
- Фоновый планировщик: проверка каждые 5 минут, запуск по интервалу при
  включённом автобэкапе.
- API: `GET/POST /api/settings/backup/s3/*` — настройки, тест подключения,
  ручной запуск. Учётные данные S3 шифруются в `data.json` (`enc::v1::`).

### Changed
- **Restore из файла**: перед перезаписью создаётся `data.json.pre-restore.<ts>`
  на PVC (защита от ошибочного upload).
- `.gitignore`: каталог `_ops/` (локальные ops-скрипты с доступами к серверам).

### Dependencies
- `boto3` — клиент S3 для бэкапов.

## [2026-06-07] — Шифрование секретов и атомарная запись data.json

### Security
- Секреты в `data.json` теперь **шифруются at-rest** (Fernet, ключ выводится из
  `SECRET_KEY`): `servers[].password`, `servers[].private_key`,
  `settings.telegram.token`, `settings.sync.remnawave_api_key`,
  `settings.ssl.key_text`. Шифрование прозрачно (encrypt при записи, decrypt при
  чтении), значения помечаются префиксом `enc::v1::`. Хеши паролей/токенов не
  трогаются. Plaintext читается без ошибок и до-шифровывается при первом
  сохранении (бесшовная миграция).
  ⚠️ `SECRET_KEY` — мастер-ключ: его потеря/смена делает секреты нечитаемыми.

### Changed
- **Атомарная запись `data.json`**: запись во временный файл + `os.replace` под
  `threading.Lock` (устраняет гонки и частичную запись при конкурентных
  операциях). Путь к файлу настраивается через env `DATA_FILE`.
- **Kubernetes**: PVC монтируется каталогом (`/data`) вместо файла-`subPath` —
  это нужно для атомарного `os.replace`. Существующий `data.json` становится
  `/data/data.json`, миграция бесшовная.

## [2026-06-07] — Удаление своих конфигов из бота

### Added
- Пользователь может **удалить своё подключение** из бота. Список «📂 Мои конфиги»
  остаётся одноколоночным; при открытии конфига в карточке появляется кнопка
  **🗑 Удалить это подключение** → подтверждение (✅ Да, удалить / ↩️ Отмена).
  Удалять можно только **свои** конфиги.
- Бэкенд-функция `delete_user_connection` (ownership-checked): снимает пира на
  сервере (`remove_client`) и удаляет запись. Если сервер недоступен — запись
  сохраняется, чтобы не оставить работающий «осиротевший» конфиг.

## [2026-06-07] — Уведомления и рассылка через бота

`sha-c9e8493`

### Added
- **Авто-уведомления о событиях инфраструктуры.** Бот рассылает всем
  пользователям сообщение, когда:
  - добавлен новый сервер;
  - удалён сервер;
  - на сервер установлен протокол;
  - с сервера удалён протокол.

  Служебные протоколы (`dns`, `adguard`) из рассылки исключены — по ним
  пользователи всё равно не создают конфиги.
- **Ручная рассылка (broadcast).** Произвольное объявление можно отправить:
  - из веб-панели — карточка «📢 Уведомления» в `/settings` (выбор аудитории:
    все / только админы);
  - из бота командой `/broadcast <текст>` (только для админа).
- **Тумблер авто-уведомлений** в настройках (`settings.notifications.server_events`)
  и REST-эндпоинты:
  - `GET /api/notifications/settings`
  - `POST /api/notifications/settings`
  - `POST /api/notifications/broadcast`

### Technical
- Рассылка устойчива к особенностям Telegram API: соблюдает паузы между
  отправками, обрабатывает `429` (retry_after) и `403` (пользователь
  заблокировал бота) без падения.
- Авто-уведомления выполняются «fire-and-forget» и не блокируют ответ API.
- Текст объявлений и названий экранируется (HTML-safe).

## [2026-06] — Self-service для друзей: инвайт-коды, UX бота, Telemt, деплой

### Added
- **Само-регистрация через Telegram-бота по инвайт-кодам.** Пользователь вводит
  код → регистрируется → сам создаёт конфиги (per server / protocol / device).
- **Управление инвайт-кодами** из веб-панели (`/settings`) и из бота
  (`/newcode`), REST API `/api/invite-codes`.
- **Переработанный UX бота:** пошаговый сценарий «новое устройство», «мои
  конфиги», кнопка **Статус** серверов (доступность и пинг), `/help` и
  приветствие с правилами («один пользователь — один код», «один конфиг — одно
  устройство»).
- **Уникальные авто-имена подключений** + возможность задать имя устройства
  вручную.
- **Telemt через домен:** в ссылку `tg://proxy` подставляется собственный домен
  (`public_host`) вместо голого IP; в боте — кнопка **Применить** (FakeTLS
  `t.me/proxy`-ссылка).
- **Контейнерный образ в GHCR + манифесты Kubernetes** (GitHub Actions сборка).

### Changed
- **Hardened-установка AmneziaWG:** свежие инсталляции совпадают с раскладкой
  официального приложения Amnezia (`wg0.conf`, образ `amnezia-wg`, без `S3/S4`
  в клиентском конфиге) — для корректного подключения на **iPhone/macOS**.
- AWG/WireGuard в боте отдаются **сырым `.conf`-файлом** (без `vpn://`-ссылки) —
  это и есть «Оригинальный формат AmneziaWG», который работает на Apple.
- Telemt ставится через `docker pull` + `docker compose up --no-build` (не
  требует свежего `buildx` на сервере).

### Fixed
- Автодетект раскладки AWG (`awg0.conf` vs `wg0.conf`) при генерации конфигов.
- Бот больше не «зависает» при ошибке создания конфига — исключения
  перехватываются.
- Подавлено логирование токена бота через `httpx`.
- Меню команд бота пересоздаётся при старте (убраны устаревшие команды).
