## [2026-06-07] — Маскировка токена бота

## [2026-06-07] — Читаемость статуса и справка по протоколам

### Changed
- **Окно «Статус серверов»** переоформлено: пустая строка между серверами,
  название и пинг — жирным, протоколы — курсивом под названием (через `·`).
  Шапка теперь `📊 Статус серверов · N/M онлайн`.

### Added
- В `/help` добавлен блок **«Протоколы — что выбрать»** с краткими описаниями.
  Список **динамический** — показываются только реально установленные на
  серверах протоколы (AWG-варианты схлопываются в один пункт «AmneziaWG»).

## [2026-06-07] — Уведомления и рассылка через бота

`sha-c9e8493`

### Added
- **Авто-уведомления о событиях инфраструктуры.** Бот рассылает всем
  пользователям сообщение, когда:
  - добавлен новый сервер;
  - удалён сервер;
  - на сервер установлен протокол;
  - с сервера удалён протокол.

  Служебные протоколы (`dns`, `adguard`) из рассылки исключены — по ним
  пользователи всё равно не создают конфиги.
- **Ручная рассылка (broadcast).** Произвольное объявление можно отправить:
  - из веб-панели — карточка «📢 Уведомления» в `/settings` (выбор аудитории:
    все / только админы);
  - из бота командой `/broadcast <текст>` (только для админа).
- **Тумблер авто-уведомлений** в настройках (`settings.notifications.server_events`)
  и REST-эндпоинты:
  - `GET /api/notifications/settings`
  - `POST /api/notifications/settings`
  - `POST /api/notifications/broadcast`

### Technical
- Рассылка устойчива к особенностям Telegram API: соблюдает паузы между
  отправками, обрабатывает `429` (retry_after) и `403` (пользователь
  заблокировал бота) без падения.
- Авто-уведомления выполняются «fire-and-forget» и не блокируют ответ API.
- Текст объявлений и названий экранируется (HTML-safe).

## [2026-06] — Self-service для друзей: инвайт-коды, UX бота, Telemt, деплой

### Added
- **Само-регистрация через Telegram-бота по инвайт-кодам.** Пользователь вводит
  код → регистрируется → сам создаёт конфиги (per server / protocol / device).
- **Управление инвайт-кодами** из веб-панели (`/settings`) и из бота
  (`/newcode`), REST API `/api/invite-codes`.
- **Переработанный UX бота:** пошаговый сценарий «новое устройство», «мои
  конфиги», кнопка **Статус** серверов (доступность и пинг), `/help` и
  приветствие с правилами («один пользователь — один код», «один конфиг — одно
  устройство»).
- **Уникальные авто-имена подключений** + возможность задать имя устройства
  вручную.
- **Telemt через домен:** в ссылку `tg://proxy` подставляется собственный домен
  (`public_host`) вместо голого IP; в боте — кнопка **Применить** (FakeTLS
  `t.me/proxy`-ссылка).
- **Контейнерный образ в GHCR + манифесты Kubernetes** (GitHub Actions сборка).

### Changed
- **Hardened-установка AmneziaWG:** свежие инсталляции совпадают с раскладкой
  официального приложения Amnezia (`wg0.conf`, образ `amnezia-wg`, без `S3/S4`
  в клиентском конфиге) — для корректного подключения на **iPhone/macOS**.
- AWG/WireGuard в боте отдаются **сырым `.conf`-файлом** (без `vpn://`-ссылки) —
  это и есть «Оригинальный формат AmneziaWG», который работает на Apple.
- Telemt ставится через `docker pull` + `docker compose up --no-build` (не
  требует свежего `buildx` на сервере).

### Fixed
- Автодетект раскладки AWG (`awg0.conf` vs `wg0.conf`) при генерации конфигов.
- Бот больше не «зависает» при ошибке создания конфига — исключения
  перехватываются.
- Подавлено логирование токена бота через `httpx`.
- Меню команд бота пересоздаётся при старте (убраны устаревшие команды).
